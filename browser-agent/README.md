# Browser Agent

Runs a real headful Chromium session with Playwright and connects outbound to the AI Control Center over WebSocket.

## Environment

- `CONTROL_CENTER_WS_URL` (default `ws://localhost:3000/ws/browser-agent`)
- `BROWSER_SESSION_ID`
- `BROWSER_AGENT_SHARED_SECRET` (legacy/static agent authentication; optional when using pairing code)
- `BROWSER_PAIRING_CODE` (preferred session-specific temporary 30-minute pairing code generated by the Control Center)

Never hard-code the pairing secret.

## Run

```bash
npm install
npx tsx agent.ts
```

The agent refuses file upload/download, cookie/password/storage access, and browser permission grants. CAPTCHA/2FA should use the application's human-handoff flow.
